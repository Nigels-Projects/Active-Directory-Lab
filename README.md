# Active-Directory-Lab
A hands-on cybersecurity project demonstrating end-to-end Active Directory deployment, Sysmon telemetry configuration, Splunk SIEM log ingestion, and MITRE ATT&amp;CK-mapped threat emulation

Skills Learned
 - Active Directory Domain Services (AD DS): Configuring a Windows Server Domain Controller, managing domain architecture, establishing organizational units (OUs), and structuring enterprise user/group accounts.

- Virtualization & Network Topologies: Setting up and configuring multi-node virtualized environments using VirtualBox, configuring internal networks, and managing static IP addressing and routing between machines.

- Multi-OS Environment Management: Deploying and managing Windows Server, Windows 10 client machines, and Linux environments (such as Ubuntu Server and Kali Linux) within a cohesive lab setup.
